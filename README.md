# To-Do Application

A responsive task management application built with React and Vite. The application provides a simple interface for creating, searching, completing, and deleting tasks.

## Live Demo

https://joshuaprashanth.github.io/To-Do/

## Repository

https://github.com/JoshuaPrashanth/To-Do

## Overview

The To-Do Application is a frontend project developed to demonstrate practical knowledge of React, JavaScript, component-based architecture, state management, and user interaction.

The application focuses on providing a clean and straightforward experience for managing daily tasks.

## Features

- Create and add new tasks
- Search tasks dynamically
- Mark tasks as completed
- Delete tasks
- Display tasks in an organized interface
- Responsive design for different screen sizes
- Client-side task management

## Getting Started

### Prerequisites

Make sure the following are installed on your system:

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/JoshuaPrashanth/To-Do.git
```

Navigate to the project directory:

```bash
cd To-Do
```

Install the required dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.

## Available Scripts

### Development

