# To-Do App

A simple and responsive To-Do application built with **React** and **Vite**.
This project is created for learning React concepts and practicing frontend development.

## Features

- Add new tasks
- View all tasks
- Search for tasks
- Mark tasks as completed
- Delete tasks
- Simple and clean user interface
- Responsive design

## Tech Stack

- **React**
- **Vite**
- **JavaScript**
- **HTML5**
- **CSS3**
- **ESLint**

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/JoshuaPrashanth/To-Do.git
```

### 2. Navigate to the project

```bash
cd To-Do
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local URL shown in your terminal, usually:

```text
http://localhost:5173
```
